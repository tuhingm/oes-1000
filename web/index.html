07 · About
How it works




Python in the browserThe estimators are Python (NumPy, pandas, SciPy, statsmodels, scikit-learn, XGBoost) running in Pyodide. The first run downloads Python once (about 30 MB); later runs start at once. Your file is read on your device and never uploaded.


Bayesian and regime-switching modelsThe Bayesian VARs follow the ECB's BEAR toolbox (Minnesota, Normal-Wishart, Independent Normal-Wishart and Normal-diffuse priors, FAVAR, steady-state, panel, TVP, stochastic-volatility, mixed-frequency and threshold VARs). Markov-switching models are estimated by maximum likelihood; the regression and AR versions reproduce Stata's and Hamilton's published estimates.


The same code as the guidesDifference GMM, the panel ARDL estimators, the causal designs and double machine learning use the helper files published with the guides. Static panel models reproduce linearmodels, including its small-sample scaling.


What is not hereDSGE models are solved and estimated in Dynare; see the DSGE Guide. The causal forest is a doubly robust forest, not EconML's implementation, which does not run in a browser.


Large filesEverything runs on your computer, so very large datasets and the forest-based methods take longer. Fewer trees or folds speed them up.
