# OES Intelligence

**An intelligent, browser-native environment for statistical and econometric research.**

OES Intelligence is a new architectural direction for OES-1000. It combines local data profiling, transparent methodological recommendations, statistical estimation, diagnostics, and reproducible research outputs in one browser application.

## Product principles

- **Local-first computation:** uploaded CSV data is processed in the browser using Pyodide/WebAssembly and a Web Worker. No dataset-upload or estimation API is part of this application.
- **Explainable recommendations:** methodological suggestions are generated by explicit, inspectable rules. They are decision support, not an opaque or autonomous claim that a model is universally correct.
- **Researcher control:** users select and approve the outcome, regressors, panel identifiers, and estimator before estimation.
- **Reproducibility:** analysis manifests record the selected specification, input fingerprint, software/runtime information, and results metadata.
- **Honest implementation status:** only estimators with implemented execution paths are offered as executable.

## Current foundation

The initial rebuild includes:

1. CSV upload and browser-local data profiling.
2. Missingness, variable type, uniqueness, and descriptive summaries.
3. Outcome-aware model recommendations for continuous and binary outcomes.
4. An OLS estimator with HC3 heteroskedasticity-robust inference.
5. A one-way entity fixed-effects estimator with entity-clustered covariance.
6. A binary logistic regression estimator.
7. Basic residual diagnostics and machine-readable analysis reports.
8. A Pyodide Web Worker boundary that keeps data and numerical computation in the browser.

This is the first functional foundation, not a claim that the full commercial SaaS, all OES-1000 catalogue entries, or clinical-trial module have already been rebuilt.

## Run locally

Serve the repository root over HTTP (not `file://`):

```bash
python -m http.server 8000
```

Open http://localhost:8000.

The browser loads Pyodide and compatible scientific packages from the public Pyodide CDN. The CSV file itself is passed only to the local Web Worker.

## Tests

```bash
python -m pip install -e ".[test]"
python -m pytest
```

The Python test suite checks profiling, recommendation rules, and estimator behavior. Browser-level Pyodide smoke tests are a separate validation gate.

## Privacy boundary

The application does not contain a dataset upload endpoint. The selected CSV is read by the browser, transferred to the dedicated Web Worker, and parsed in Pyodide memory. The worker loads static application code and package assets from their configured hosts; those requests are not dataset uploads. Browser extensions, user-installed scripts, or future integrations must be reviewed separately.
